# ACME Salary Management System

## Overview
A web-based employee and salary management system
developed for ACME organization.

## Problem Statement
ACME manages employee and salary information using
spreadsheets. This application provides a centralized
system for managing employee records and salary revisions.

## Technology Stack
- Java 21
- Spring Boot
- Spring Data JPA
- H2 Database
- React
- Vite
- Axios

## Features
- Employee CRUD
- Search and filtering
- Pagination
- Salary revision history
- Dashboard
- 100,000 employee data seeder

## Architecture
Spring Boot REST API + React frontend.

## Database Design
Employee, Department and Salary History.

## How to Run

### Backend
./mvnw spring-boot:run

### Frontend
cd frontend
npm install
npm run dev
